# ai-advent-challenge-06 - 14.11.2026

Агент с tool-calling: пользователь пишет запрос, модель сама решает, какой инструмент
вызвать, код выполняет вызов и возвращает результат обратно в модель. Цикл повторяется,
пока модель не даст финальный ответ.

Стек: **Vite 8 + Vue 3 + TypeScript**, OpenAI-совместимый Chat Completions API.
Тесты — Vitest.

## Install

Зависимости ставятся один раз из корня репозитория:

```sh
nvm use          # Node 24, см. .nvmrc
npm install
```

## Run

```sh
npm run dev -w 06
```

→ http://localhost:5173/

Сборка и тесты:

```sh
npm run build -w 06
npm test -w 06
```

## Настройка API

В правой панели «Настройки»:

1. Выбери провайдера: **DeepSeek**, **Moonshot / Kimi** или «Другой OpenAI-совместимый».
2. Base URL и модель подставятся из пресета, но их можно изменить вручную.
3. Вставь свой API-ключ.
4. Проверь endpoint внизу блока — запросы уходят на `POST <base>/chat/completions`.

Ключ хранится только в памяти вкладки. Чекбокс «Запомнить ключ» сохраняет его в
`localStorage` — включай только на своём компьютере. В репозиторий ключ не попадает.

Оба пресета (DeepSeek и Moonshot) разрешают CORS-запросы из браузера с
`http://localhost:5173`. Если запустить dev-сервер на другом порту или использовать
провайдера без CORS, браузер заблокирует запрос — тогда нужен прокси.

## Инструменты

| Инструмент | Аргументы | Что делает |
|---|---|---|
| `get_current_time` | `timezone?` | Текущие дата/время, unix timestamp и день недели через `Intl` |
| `calculate` | `expression` | Арифметика: `+ - * / % ^`, скобки, `sqrt`, `abs`, `round`, `floor`, `ceil`, `min`, `max`, `pi`, `e` |
| `convert_currency` | `amount`, `from`, `to` | Конвертация по зашитому курсу: USD, EUR, GBP, RUB, CNY, JPY, KZT, TRY, INR, BYN |

Калькулятор — собственный рекурсивный парсер, без `eval` и `new Function`.
Курсы валют фиксированные (учебные), из интернета не обновляются.

## Сценарии проверки

| Сценарий | Запрос | Ожидаемое поведение |
|---|---|---|
| Без инструментов | «Объясни в двух предложениях, чем HTTP отличается от HTTPS» | Один запрос к LLM, `tool_calls` нет |
| Один инструмент | «Сколько будет 1234 * 56 + 78?» | Вызов `calculate`, затем финальный ответ |
| Два инструмента подряд | «Переведи 250 USD в EUR, затем увеличь результат на 15%» | `convert_currency` → результат 230 EUR → `calculate` → 264.5 EUR |

Те же три запроса доступны кнопками на стартовом экране.

## Где смотреть API-запросы

- **Вкладка «API»** в правой панели — журнал всех HTTP-запросов: полный `messages`,
  схемы инструментов, `response`, `tool_calls`, `usage`, длительность и ошибки.
  Любой запрос можно раскрыть, скопировать или экспортировать весь журнал в JSON.
- **DevTools → Network** — реальный `POST /chat/completions` с заголовками и телом.
  В `Authorization` будет твой ключ: не показывай его на скриншотах и в записи экрана.
- **Трасса в сообщении** — по итерациям видно, какой инструмент вызван, с какими
  аргументами и что он вернул.

## Как устроено

```
src/
  agent/
    Agent.ts          # цикл: запрос → tool_calls → выполнение → tool-сообщения → повтор
    ToolRegistry.ts   # схемы инструментов, вызов, обработка ошибок
  api/
    llm.ts            # HTTP-клиент OpenAI-совместимого API
  tools/
    time.ts           # get_current_time
    calculator.ts     # calculate + безопасный парсер выражений
    currency.ts       # convert_currency
  components/
    SettingsPanel.vue # провайдер, ключ, параметры, список инструментов
    MessageBubble.vue # сообщения и трасса вызовов
    ApiLogPanel.vue   # журнал запросов/ответов
  App.vue             # состояние чата, история, запуск агента
```

Агент — отдельный класс `Agent`, а не набор вызовов в компоненте. Он получает
`ToolRegistry`, историю сообщений и колбэки для UI, а наружу отдаёт финальный текст,
шаги и полный список сообщений. Ошибка инструмента не роняет цикл: она возвращается
модели как `{"ok": false, "error": "..."}`, чтобы та могла исправиться.

## Тесты

```sh
npm test -w 06
```

9 тестов без реального API-ключа: парсер выражений и tool-loop с замоканным `fetch`
(ответ без инструментов, один вызов, два вызова подряд, ошибка инструмента).

## Ограничения

- Нет стриминга: ответ приходит целиком после каждого запроса.
- Максимум итераций ограничен настройкой (по умолчанию 6) — защита от бесконечного цикла.
- Курсы валют и список инструментов зашиты в код.
- Ответ модели выводится как обычный текст, без markdown-рендера.
