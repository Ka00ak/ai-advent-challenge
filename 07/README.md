# ai-advent-challenge-07 - 10.11.2026

Агент с tool-calling **и сохранением контекста**. Вся история диалога — реплики
пользователя, ответы ассистента, `tool_calls` и результаты инструментов — пишется в
JSON и автоматически загружается обратно после перезапуска приложения. Диалог
продолжается так, как будто агент не выключался.

Сделано на основе [06](../06): тот же цикл tool-calling, инструменты и интерфейс,
добавлен слой персистентности.

Стек: **Vite 8 + Vue 3 + TypeScript**, OpenAI-совместимый Chat Completions API.
Тесты — Vitest.

## Install

Зависимости ставятся один раз из корня репозитория:

```sh
nvm use          # Node 24, см. .nvmrc
npm install
```

## Run


## Настройка API

В правой панели «Настройки»:

1. Выбери провайдера: **DeepSeek**, **Moonshot / Kimi** или «Другой OpenAI-совместимый».
2. Base URL и модель подставятся из пресета, их можно изменить вручную.
3. Вставь API-ключ.
4. Проверь endpoint — запросы уходят на `POST <base>/chat/completions`.

API-ключ в историю диалога не попадает. Чекбокс «Запомнить ключ» по-прежнему
сохраняет его отдельно в `localStorage` — только для своего компьютера.

## Как хранится контекст

История лежит в `localStorage` под ключом `lab07.conversation.v1`. Это обычный
JSON-снимок:

```json
{
  "version": 1,
  "id": "conversation-…",
  "createdAt": "2026-11-14T10:00:00.000Z",
  "updatedAt": "2026-11-14T10:01:00.000Z",
  "messages": [
    { "role": "user", "content": "Сколько будет 1234 * 56 + 78?" },
    {
      "role": "assistant",
      "content": null,
      "tool_calls": [
        {
          "id": "call_1",
          "type": "function",
          "function": {
            "name": "calculate",
            "arguments": "{\"expression\":\"1234*56+78\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_1",
      "name": "calculate",
      "content": "{\"ok\":true,\"result\":{\"result\":69182}}"
    },
    { "role": "assistant", "content": "Получается 69 182." }
  ]
}
```

Системный промпт не сохраняется: он подставляется заново при каждом запуске.
Сохраняется именно контекст диалога, поэтому смена модели или системного промпта
не ломает загрузку.

### Что происходит при перезапуске

1. При старте `App.vue` читает JSON из `localStorage` и валидирует его.
2. Из массива `messages` восстанавливается UI-лента, включая trace вызовов
   инструментов: имя, аргументы, результат или ошибка.
3. При следующей реплике весь восстановленный массив уходит в модель вместе с
   новым `user`-сообщением. Модель видит прошлые результаты инструментов и может
   ссылаться на них.
4. Каждое новое сообщение (user / assistant / tool) сразу дописывается в JSON,
   поэтому история не теряется даже при закрытии вкладки посреди ответа.

Если приложение было закрыто между `assistant(tool_calls)` и `tool`-ответом,
перед следующим запросом `repairToolCallSequence()` добавит недостающие
tool-сообщения с ошибкой — Chat Completions API требует ответ на каждый вызов.

## Интерфейс

- **Вкладка «История»** — состояние автосохранения, размер JSON, количество
  `user` / `assistant` / `tool` сообщений, `tool_calls` и сырой массив `messages`.
- **Скачать JSON** — экспорт снимка диалога в файл.
- **Загрузить JSON** — импорт ранее сохранённого файла (с валидацией версии и
  структуры сообщений).
- **Очистить / Новый диалог** — удаляет сохранённую историю.
- **Зелёная плашка в шапке** — последнее сохранение и размер истории.
- **Баннер после перезагрузки** — сколько сообщений и tool-вызовов восстановлено.

## Сценарии проверки

| Сценарий | Запрос | Ожидаемое поведение |
|---|---|---|
| Без инструментов | «Объясни в двух предложениях, чем HTTP отличается от HTTPS» | Один запрос к LLM, `tool_calls` нет |
| Один инструмент | «Сколько будет 1234 * 56 + 78?» | Вызов `calculate`, затем финальный ответ |
| Два инструмента подряд | «Переведи 250 USD в EUR, затем увеличь результат на 15%» | `convert_currency` → 230 EUR → `calculate` → 264.5 EUR |

Эти же запросы доступны кнопками на стартовом экране.

### Проверка сохранения контекста (главный сценарий)

1. Запусти `npm run dev -w 07` и открой http://localhost:5173/.
2. Спроси: **«Сколько будет 1234 * 56 + 78?»** — агент вызовет `calculate`.
3. Убедись, что во вкладке «История» появились `user`, `assistant` с
   `tool_calls`, `tool` с результатом и финальный `assistant`.
4. Перезагрузи страницу (F5) или останови и снова запусти dev-сервер.
5. Диалог и trace восстановятся, появится баннер «История восстановлена из JSON».
6. Продолжи: **«А умножь прошлый результат на 2»** — модель должна взять
   результат `69 182` из истории и ответить `138 364`.
7. Открой вкладку «API»: в новом запросе видно весь восстановленный массив,
   включая прошлые `tool_calls` и `tool`-сообщения.

Дополнительно: скачай JSON, нажми «Новый диалог», затем «Загрузить JSON» —
диалог вернётся из файла.

### Результат живой проверки

Сценарий прогнан на реальном `deepseek-chat`:

1. Запрос «Сколько будет 1234 * 56 + 78?» → модель вызвала `calculate`,
   результат `69 182` сохранён в JSON вместе с `tool_calls`.
2. История загружена в новый экземпляр агента (имитация перезапуска).
3. Запрос «А теперь умножь прошлый результат на 2» → в запросе к API были прошлые
   `assistant.tool_calls` и `tool`-сообщение с результатом, ответ — `138 364`.

Этот же сценарий закреплён в `tests/agent.test.ts` с замоканным `fetch`, поэтому
проверяется без сети и без ключа.

## Как устроено

```
src/
  agent/
    Agent.ts          # цикл tool-calling + onMessageAppended для автосохранения
    history.ts        # починка незавершённых tool_calls перед запросом
    ToolRegistry.ts   # схемы инструментов, вызов, обработка ошибок
  api/
    llm.ts            # HTTP-клиент OpenAI-совместимого API
  storage/
    conversation.ts   # JSON-снимок, валидация, localStorage, восстановление UI
  tools/
    time.ts           # get_current_time
    calculator.ts     # calculate + безопасный парсер выражений
    currency.ts       # convert_currency
  components/
    SettingsPanel.vue # провайдер, ключ, параметры, список инструментов
    MessageBubble.vue # сообщения и trace вызовов
    HistoryPanel.vue  # статистика, JSON, экспорт/импорт/очистка
    ApiLogPanel.vue   # журнал запросов/ответов текущей сессии
  App.vue             # состояние чата, загрузка/сохранение истории, запуск агента
```

`Agent` не знает про localStorage: он получает историю и отдаёт каждое новое
сообщение через `onMessageAppended`. `App.vue` дописывает сообщения в канонический
массив и сохраняет JSON. Такое разделение позволяет тестировать агент и хранилище
по отдельности.

## Тесты

```sh
npm test -w 07
```

Тесты без реального API-ключа:

- парсер выражений;
- tool-loop с замоканным `fetch`: ответ без инструментов, один вызов, два вызова
  подряд, ошибка инструмента;
- **продолжение диалога после «перезапуска»**: история сохраняется в JSON,
  загружается в новом экземпляре и уходит в модель вместе с `tool_calls` и
  результатами;
- сохранение/загрузка localStorage, валидация повреждённого JSON и импорта;
- восстановление UI-trace из `messages`;
- починка незавершённой последовательности `tool_calls`.

## Ограничения

- Одна сохранённая беседа на браузер (один ключ `localStorage`).
- Лимит `localStorage` — обычно около 5 МБ; очень длинные диалоги могут упереться
  в квоту (ошибка показывается в шапке и вкладке «История»).
- Журнал HTTP-запросов (вкладка «API») хранится только в памяти текущей сессии.
  Сохраняется контекст диалога, а не отладочный лог.
- Нет стриминга: ответ приходит целиком после каждого запроса.
- Курсы валют и список инструментов зашиты в код.
