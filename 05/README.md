# ai-advent-challenge-05 - 06.11.2026

Install
```sh
python3 -m venv .venv
source .venv/bin/activate
pip install streamlit openai
```

Run
```sh
streamlit run 05/app.py
```

## Result

Для используемой выборки (задачи были сгенерированы дипсиком) было достаточно и дешевой модели. Более дорогие модели не показали преимуществ. Полагаю модели могут быть натренированы на подобных "олимпиадных" задачках и более мощные/дорогие модели будут показывать преимущество в более боевых условиях.
