# deepseek-flash — задача 7

**Задача:**
Дан массив целых чисел. Найдите максимальную сумму подмассива (задача Кадане). А теперь усложнение: массив по кругу (последний элемент соседствует с первым) — найдите максимальную сумму непустого циклического подмассива. В чём подвох, если все числа отрицательные?

**Ответ:**
Обычный **Kadane**:

```python
def max_subarray(a):
    cur = best = a[0]
    for x in a[1:]:
        cur = max(x, cur + x)
        best = max(best, cur)
    return best
```

Работает за `O(n)` по времени и `O(1)` по памяти.

Для **циклического** массива максимум достигается в одном из двух случаев:

1. Подмассив не переходит через границу массива — это обычный Kadane.
2. Подмассив переходит через границу — тогда он имеет вид «суффикс + префикс».  
   Его сумма равна:

```text
total - сумма выброшенного среднего куска
```

Чтобы максимизировать такую сумму, нужно выбросить подмассив с **минимальной** суммой:

```text
candidate_wrap = total - min_subarray_sum
```

Итог:

```text
answer = max(max_subarray_sum, total - min_subarray_sum)
```

Но есть подвох.

### Подвох с отрицательными числами

Если **все числа отрицательные**, например:

```text
[-5, -2, -3]
```

то обычный максимум подмассива равен `-2`.

При этом минимальный подмассив — это весь массив, его сумма `-10`. Тогда:

```text
total - min_subarray_sum = -10 - (-10) = 0
```

Но `0` соответствует **пустому подмассиву**, а по условию подмассив должен быть **непустым**. Поэтому для всех отрицательных чисел нельзя брать `0`; правильный ответ — максимальный элемент, то есть `-2`.

Код:

```python
def max_circular_subarray(a):
    total = a[0]

    cur_max = best_max = a[0]
    cur_min = best_min = a[0]

    for x in a[1:]:
        total += x

        cur_max = max(x, cur_max + x)
        best_max = max(best_max, cur_max)

        cur_min = min(x, cur_min + x)
        best_min = min(best_min, cur_min)

    # Все числа отрицательные: непустой ответ — максимальный элемент
    if best_max < 0:
        return best_max

    return max(best_max, total - best_min)
```

Пример:

```python
print(max_circular_subarray([5, -3, 5]))     # 10
print(max_circular_subarray([-5, -2, -3]))   # -2
print(max_circular_subarray([1, -2, 3]))     # 4
print(max_circular_subarray([1, 2, 3]))      # 6
```

Кратко: для циклического массива ответ — это  
`max(обычный максимум, total - минимум подмассива)`,  
но если все числа отрицательные, нужно вернуть максимальный элемент, а не `0`.
